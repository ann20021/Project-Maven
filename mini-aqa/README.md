\# mini-aqa



Учебный Maven-проект на Java 21 с JUnit 5.



\## Команды для работы



1\. \*\*Прогнать тесты:\*\*

&#x20;  ```bash

&#x20;  mvn test

&#x20;  ```



2\. \*\*Собрать проект в JAR-артефакт:\*\*

&#x20;  ```bash

&#x20;  mvn package

&#x20;  ```



3\. \*\*Запустить собранное приложение:\*\*

&#x20;  ```bash

&#x20;  java -cp target/mini-aqa-1.0.jar app.App

&#x20;  ```
